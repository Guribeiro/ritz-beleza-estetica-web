## 🚘 About the project

Website for **Ritz Beleza & Estética**, a beauty salon at Arujá Lagos Boulevard, Arujá – SP ([@ritz.aruja](https://www.instagram.com/ritz.aruja/)).

The visual direction is art déco: a stepped brass arch frames the hero, a hotel-style "carta" lists the services, and every service books directly through WhatsApp with a pre-filled message.

### Stack

- [Next.js 16](https://nextjs.org) (App Router) + React 19
- [Tailwind CSS 4](https://tailwindcss.com) + [shadcn/ui](https://ui.shadcn.com) (Radix)
- TypeScript, ESLint 9 (flat config), Prettier 3, Husky + commitlint

Salon data (phone, WhatsApp, address, hours, services) lives in `src/config/salon.ts`.

```bash
pnpm install
pnpm dev
```
